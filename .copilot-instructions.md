# Copilot Instructions for arr-extension

## Custom Commands

### /graphify
Generates a knowledge graph of the codebase with architecture analysis.

**Usage:**
```
/graphify                     # full pipeline on current directory
/graphify <path>              # full pipeline on specific path
/graphify <path> --update     # incremental - re-extract only new/changed files
/graphify <path> --no-viz     # skip visualization, just report + JSON
/graphify query "<question>"  # BFS traversal - broad context
```

**Outputs:**
- `graph.json` — GraphRAG-ready knowledge graph
- `graph.html` — Interactive visualization 
- `GRAPH_REPORT.md` — Architecture summary with god nodes and surprising connections

When invoked, the agent will analyze code structure, types, and relationships to build clustered communities and identify core abstractions and hidden patterns.
